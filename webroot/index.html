状态

预设

只修改配置，不会立即执行。选完可以去「分类」页微调，再点下方「保存并应用」。

说明

  • 每一项改动都会记录原值，「全部还原」或卸载模块会逐项恢复。
  • 网络拦截 = hosts 域名 + 按 UID 的 iptables（filter 表自有链 ANXIMI_OUT），不使用 mangle/nat/路由标记，与 Surfing 共存。
  • system UID (1000) 的核心组件不会被 iptables 拦截（否则整机断网），只靠 hosts；建议在 mihomo 里引用导出的规则集补全。
  • 所有选中用户（含第二空间、Island 工作资料、双开空间）都会处理。

系统设置项

应用时记录原值，还原时写回。标注「待验证」的是 MIUI 键名，在 HyperOS 3 上可能已无作用（写入无害）。

组件禁用

对某个包（比如必须保留的安全中心）只禁用其中的上传/统计组件。只能扫描到在 dumpsys 中出现的组件。

直接编辑 components.conf
